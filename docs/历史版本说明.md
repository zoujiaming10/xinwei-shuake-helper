## 2.5.4 图片题每隔3秒重试，最多3次

图片题返回空答案或单选题返回多个答案时，首次失败后等待3秒，发起第1次重试；仍失败则再次等待3秒，直到最多3次重试。首次请求加上重试总计最多4次API调用，次数共用，不叠加上版纠正次数。每次间隔从上一次失败回复后计算，不是固定3秒内必须返回。

有效答案一旦取得便立即结束重试，继续填写和下一题；3次都失败才暂停，保留批量进度。日志显示“3秒后重试（第1/3次）”等进度。重试保持清晰图片，不累积历史错误答案，全部实际请求与可取得的Token用量计入统计，因此费用可能增加。

等待发生在后台，不阻塞软件界面；停止、暂停批量、切换检测页或更改设置会取消旧任务的后续请求。鉴权失败等HTTP错误、图片加载失败或题目变化不属于此类模型答案重试，仍会停止或保留旧答案拦截。

关闭旧版后运行XinweiDesktop-2.5.4.exe，确认标题2.5.4。已有设置和Key沿用，使用旧快捷方式的请在新版重新创建。

以下历史版本说明中的“最多一次纠正/两次请求”已由本节图片题策略替代；纯文字单选多答仍最多纠正一次。

### 图片和Token

只截取本题题干及选项的图片区域并随题目发送给官方DeepSeek接口，不发送整个桌面或浏览器窗口，不把带登录信息的图片地址交给模型。图片仅在内存中处理，不写入诊断或用量文件；用量文件仍只缓存答案。

纯文字题沿用一次文字请求。图片题正常只发一次请求，图片空答案或单选答案数量冲突时最多追加一次纠正请求，图片最长边压到1600像素并用JPEG压缩，继续采用简短JSON答案，使用缓存避免相同图片重复请求。图片会额外消耗输入Token，不能按纯文字题估算费用。“省Token”会让服务端进一步缩小图片，可能丢失公式和小字，数学题建议保持清晰模式。每日请求上限和每日Token预算没有恢复。

图片未加载完成先等待；加载失败或15秒后仍未完成会暂停，不发送缺图题。返回答案时会再次核对图片，图片已变化则不填写旧答案。超过32张图片、单张展示尺寸异常或压缩后总大小超过12MB时暂停，避免失控请求；这不是每日预算。

仅支持可识别页面里的选择/判断/简答结构。图片中的填空、附件下载题、拖拽题、模糊小图、超长推导等仍可能需要手动处理。图片内容和网页题干均作为题目数据，不作为程序指令执行。模型可能识图或作答错误，不能保证正确率。

已在真实Edge的模拟页面及模拟API上验证图片判断、五个纯图片多选选项、纯图片简答、跨域iframe、SVG/canvas、图片变化拦截、加载失败、低分辨率及缓存、连续图片题自动作答。打包版另做组件和截图编码自检。未使用真实Key调用计费API，尚未在你的实际图片作业页面验证。

## 2.4.0 三项修复

### PPT/PDF等非视频课件

连播会读取目录课件类型：视频图标优先识别视频；PPT/PDF/文档图标、对应类型提示或明确扩展名标为非视频课件。寻找下一节时跳过已识别的非视频课件；当前已在PPT页、或者视频结束弹层跳到了PPT页时，也从目录继续找下一节视频候选项。无法确定类型的条目不凭名称随意跳过，无法识别目录时不能保证跳过课件。

跳过只表示不在该页停留，不伪造完成记录；如果学校要求课件也必须完成，跳过不会使它自动记为已完成。

### 桌面启动

此版提供单文件 `XinweiDesktop-2.5.4.exe`，运行时不需要旁边的_internal文件夹。请先把exe放在固定位置，双击运行；也可在程序上方点击“创建桌面快捷方式”。快捷方式记录exe完整路径和启动目录，适配Windows重定向/OneDrive桌面。创建后若移动或删除exe，需重新创建快捷方式。

单文件启动会把运行组件临时解压到系统临时目录，首次启动可能比原目录版慢一些；它不是安装器，不需安装Python，仍需要本机Edge。

### 密钥自动保存

填写API Key后约0.7秒自动保存，无需勾选保存或点击保存按钮；退出时也会保存尚未保存的密钥。使用当前Windows账户DPAPI加密，沿用%LOCALAPPDATA%\XinweiDesktop\settings.json，同一账户重启程序后恢复，和exe所在目录及快捷方式启动位置无关。

旧版未保存过的密钥无法恢复，请升级后再填写一次。程序显示“密钥已加密自动保存”表示写入成功。不要分享数据目录。切换Windows账户或系统密钥损坏时可能无法解密，此时会提示重新填写，而不再静默清空。

保留“删除密钥”按钮；修改密钥会停止当前自动操作，避免继续使用旧密钥。模型等其他设置仍需点击“保存并应用设置”。

## 批量模式的识别与停止条件

适配本次截图中的“做作业”卡片、题目数量、“未完成”分类，以及可识别的Element分页或“下一页”按钮。只处理当前课程，不切换其他课程，不进入“我的考试”，不执行重做。

每份作业从答题卡的第1题开始逐题核对，确认已填写题数等于卡片标注题数后才点击“提交作业”。看到明确的“提交成功/作业已提交/交卷成功”提示后才记为完成。成功后返回未完成列表刷新处理下一份，已有记录不重复提交。

未知弹窗、缺少答案、平台提示漏答、API失败、低信心、题数不一致、无法确认第1题、提交成功未确认、无法识别分页或卡片会暂停。不会把错误页面或未知空白当作所有作业完成，不会自动重试交卷。遇到此类情况请检查页面和运行记录。

不支持的列表改版、平台提交结果页/确认弹窗差异可能导致暂停；截图只能提供外观，无法保证全部真实DOM结构都与测试一致。

## 题型和正确率

支持可识别的文字/图片单选、多选、判断（2–26个选项）以及简答富文本/textarea/部分iframe编辑器。图片题需启用图片识别并使用deepseek-flash；附件、填空或未知结构暂停。选择题最大输出192 tokens、简答384 tokens；关闭thinking，通常每题一次请求；单选答案数量冲突时最多纠正一次，其他失败不自动重试。

模拟百分比只控制参考答案采纳比例，部分选择题会主动改选，不保证真实正确率或得分；简答题不参与模拟。谨慎模式使用模型自报信心，低于阈值暂停，也不代表经过校准的正确率。自动提交前请自行决定是否启用这些策略。

## 验证与限制

- 在实际Edge的合成页面上通过两份作业全流程测试，含确认弹窗、成功提示、返回列表和空列表终止。
- 已检查题数不足不提交、停止取消批量、旧请求/Token上限不再拦截。
- 原有连续答题、答案格式解析、主观题和混合题型测试保留。
- 未登录你的真实账户执行批量交卷，没有提交真实作业，也未使用真实API Key进行这些测试。模型质量和平台实际保存/评分需自行验证。

API Key自动使用Windows DPAPI保护；程序数据位于%LOCALAPPDATA%\XinweiDesktop，包含独立Edge登录信息，请勿分享该目录。导出诊断不含密钥、Cookie和视频源地址，分享前仍请检查页面路径。
